What it does

Three panels. One dashboard.

CPU / Cyan

Live processor utilization, history graph, detected processor model, clock frequency, uptime, and system RAM percentage. Includes a toggleable dog and personal note.

GPU / Gold

Adapter name, GPU engine utilization, dedicated graphics memory, 3D engine activity, shared GPU memory, and copy-engine activity. Includes a toggleable cat.

RAM / Purple

Memory utilization, used and available capacity, installed module manufacturers, transfer speed, and DDR generation. Includes a toggleable pygmy hippo.

Hover tooltips explain technical metrics. Some readings depend on the hardware, graphics driver, and available Windows counters; unsupported readings may show N/A.

Under the hood

How it works

01 · Rainmeter INI

The .ini file defines the layout, typography, colors, bars, history graphs, images, tooltips, and click actions. Rainmeter updates its meters as measurements change.

02 · PowerShell

GPUStats.ps1 reads Windows graphics performance counters and adapter information; RAMInfo.ps1 queries installed memory-module details. Their output feeds the Rainmeter meters.

03 · Portable resources

The @Resources directory keeps scripts and image assets next to the skin, so users can move the complete folder without editing hardcoded personal paths.

What is a Windows GPU performance counter?

Windows records graphics-engine activity and graphics-memory usage for supported drivers. This project reads those counters instead of requiring a separate GPU sensor-monitoring application. They do not reliably expose GPU temperature, core frequency, or board power. Counters may span multiple adapters and may not correspond exactly to the displayed adapter name.

Get started

Install version 7

  1. Install Rainmeter on Windows.
  2. Download the v7 ZIP and extract the enclosed TRON_Telemetry_Portable_v7 folder into Documents\Rainmeter\Skins\.
  3. Keep @Resources inside that folder beside the .ini file.
  4. Open Rainmeter Manage, select the TRON_Telemetry_Portable_v7 skin, and load TRON_Telemetry_Portable_v7.ini.
  5. Hover over metric labels to learn what they mean, and use the character and note toggles to customize the view.

Requirements: Windows, Rainmeter, Windows PowerShell 5.1, and compatible graphics drivers for GPU counters. No separate GPU sensor application is required. PowerShell execution and security policy may affect script-based readings.

Version 7 is preserved as a project milestone. It was tested on one Windows system; behavior on other hardware has not been independently validated.
